# Stock photography slots

The home page and What's On listings read photos from this folder. Until a file is
added, each slot falls back to a stage-lit gradient, so a missing photo never looks
broken. (The broken images on the production pages live in `/images/productions/`
and are broken on purpose. Don't add files there.)

Source from Unsplash (free licence, no attribution required, though credit is nice).
Landscape, roughly 1600px wide, compressed JPEG under ~250KB each.

| File | Used for | Look for |
| --- | --- | --- |
| `music.jpg` | Hero slide 1, "An Evening of Music" cards, Music genre tile | Live music on stage, warm spotlights |
| `performance.jpg` | Hero slide 2, "Performance" cards | Performer on a lit stage, cool blue light |
| `theatre.jpg` | Hero slide 3, "Theatre – see website" cards, Theatre genre tile | Actors on stage, or a red curtain |
| `dance.jpg` | Hero slide 4, "Dance" card, Dance genre tile | Contemporary dancer mid-movement |
| `comedy.jpg` | Comedy genre tile | Microphone on stand, single spotlight |
| `family.jpg` | Family genre tile | Children's theatre, puppets, or a bright audience |
| `talks.jpg` | Talks genre tile | Speaker at a lectern, or a book event |
| `auditorium.jpg` | "Support Enyold" band | Empty auditorium, rows of red seats |

The hero and support band put a dark gradient over the left side for legibility, so
photos with the subject on the right work best there.
